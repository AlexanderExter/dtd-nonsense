# Books Directory

Core reference material for the D:TD rulebooks. Per-chapter `.mdx` files with YAML frontmatter, split from original PDF extractions.

This is the **Tier 1 canonical source** for all rules content.

## Directory Structure

```text
books/

├── book-1-dungeons-the-dragoning/   (23 files, ~14,500 lines)
│   ├── 00-title.mdx                 Title and credits
│   ├── 01-introduction.mdx          Chapter I
│   ├── 02-character-creation.mdx    Chapter II
│   ├── ...
│   ├── 17-antagonists.mdx           Chapter XVII
│   ├── 18–20-appendix-*.mdx         Appendices A–C
│   ├── 21-supplemental-content.mdx  Cross-reference to Book 2

└── book-2-for-a-few-subtitles-more/ (30 files, ~10,200 lines)
    ├── 00-title.mdx                 Title and credits
    ├── 01-introduction.mdx          Chapter I
    ├── ...
    ├── 11-equipment.mdx             Chapter XI
    ├── 12-appendices-intro.mdx      Appendices section header
    ├── 13–27-appendix-*.mdx         Appendices A–O
    ├── 28-closing.mdx               Closing text

```

## Frontmatter Schema

Every file includes YAML frontmatter:

```yaml
---
title: "Chapter IV: Races" # Display title
book: 1 # 1 or 2
chapter: 4 # Chapter number (omitted for appendices/special sections)
order: 4 # Sort order within the book
type: "chapter" # chapter | appendix | title | closing | reference | section-header
---
```

## Relationship to Other Directories

| Directory             | Role                                                            |
| --------------------- | --------------------------------------------------------------- |
| `books/`              | **This directory** — core reference, per-chapter split          |
| `cleaned-references/` | Succinct combined reading references merged by topic            |

These files are a direct mechanical split of the original extracted monoliths — no content transformation was applied beyond:

1. Adding YAML frontmatter to each file
2. Fixing `# Chapter XII: Equipment --` → `# Chapter XII: Equipment` (trailing artifact)
3. Stripping trailing blank lines from each chapter

All editorial comments (`<!-- EDITOR: -->`, `<!-- NOTE: -->`) are preserved.

Content will diverge from sources as editorial process continues. In the event of irrecoverable errors in this directory, the [original PDFs](https://static.wikitide.net/1d6chanwiki/f/fc/Dungeons_the_Dragoning.pdf) are available online, but the creation of a new extraction script would be preferred. As a technical note, the first extraction attempt produced very dirty single file docs, at the very least the single-file approach should be avoided as it is taxing to LLMs and error-prone for manual review.

## Known Irregularities

- **Book 2, Appendix D** heading reads `# advanced rules: Tracking` (lowercase) in source — frontmatter title is normalized to "Appendix D: Tracking"
- **Book 2, fiction interludes** (VIDEO 2, VIDEO 4, etc.) are H2 headings embedded within their containing chapters — not split out
- **Book 2, Appendix E** (`17-appendix-e-astropaths-and-navigators.mdx`) is only 9 lines — content may be incomplete in source

## Generated By

Original split performed by a one-time utility script. The `archive/` directory (containing the extraction script and intermediate monolithic files) has been removed — the [original PDFs are available online](https://static.wikitide.net/1d6chanwiki/f/fc/Dungeons_the_Dragoning.pdf) for reference.
