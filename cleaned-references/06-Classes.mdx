## Class Rules

Classes define what a character can spend XP on — only characteristics and skills from your current class. Each class grants specific [feats](./07-Feats.mdx) and may include Sword School or Magic School access.

**Prerequisites:** Each class requires skills, characteristics, or other classes before entry.

**Single Class:** Only one class at a time. Complete all mandatory feats to finish a class, then choose a new one. Cannot buy from old class lists after leaving (except via Free Study).

**Level** determines:

- Maximum rank for Power Stat, Sword Schools, and Magic Schools (capped at character level)
- Effects of many spells and feats

A character's level = highest-level class completed. Example: Fighter 4, Bard 2 = Level 4.

**Optional Feats:** Not required to complete class.

**Choice Feats:** Marked "Mandatory (Choice)" with OR. Choose one; cannot get the other from this class.

:::tip[Clarification]
If you already have a mandatory feat from another source, choose a replacement from the same class's optional feats or another mandatory feat you don't yet have.
:::

## Free Study

After finishing a class:

- Buy optional feats from completed classes
- Improve skills/characteristics/schools from completed class lists
- Improve other skills/characteristics at **double cost**

## Leveling Procedure

1. Choose a class (meet prerequisites; cannot be more than one level above current)
2. Spend XP on: characteristics, skills, mandatory/optional feats, Magic/Sword Schools, Power Stat — all capped per class list and Level
3. Complete all mandatory feats before changing classes

See [Character Creation](./02-Char-Creation.mdx) for starting class selection.
